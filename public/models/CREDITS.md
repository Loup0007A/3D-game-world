# Modèles 3D du niveau 101

Modèles téléchargés sur Sketchfab, puis optimisés pour le web (textures
réduites en WebP, maillages simplifiés, animations rééchantillonnées,
compression meshopt). Les couleurs de certains sont modifiées dans le jeu.
